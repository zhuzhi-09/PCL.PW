AI 排障

PCL.PW 可以把游戏日志交给 AI 分析，并允许 AI 通过启动器提供的固定操作查看版本、搜索并安装模组、修改配置、备份与恢复。接口和 API Key 都由你自己填写，费用由你的 AI 服务商收取。

能做什么

  • 分析游戏日志和崩溃报告，指出 Java 版本、内存、模组冲突等常见原因；
  • 查看已安装的版本、加载器、Java、内存、模组与存档；
  • 在 Modrinth 搜索模组、光影、资源包和数据包，并安装到指定版本（含必需的前置模组）；
  • 启用或禁用模组，替换或删除模组文件；
  • 读取和修改 config 文件夹中的配置文件与 options*.txt，修改前自动备份；
  • 备份存档、模组与配置，并从备份恢复。
info

AI 不是官方的游戏支持。它只能基于你发送的日志和启动器提供的信息分析，回答可能有误；涉及修改文件的操作都会先显示要改什么，让你确认。

设置接口

打开「设置 → AI 排障」，选择接口类型并填写地址、模型与 API Key：

接口类型说明
OpenAI 兼容接口DeepSeek、Kimi、OpenRouter、OpenAI、本机 Ollama 等，填写对应的 .../v1 地址。
Anthropic 接口Claude 系列模型，地址一般填 https://api.anthropic.com。
  • 接口地址：设置页提供常见服务的预设，也可以自己填。本机服务（例如 Ollama 的 http://localhost:11434/v1）不需要 API Key。
  • 模型：可以从接口获取模型列表后选择，也可以手动填写模型 ID。
  • API Key：只保存在本机，Windows 上会加密保存，不会写进配置文件；请求只会发送到上面填写的地址。
  • 上下文长度与自动压缩：上下文较长的模型可以调大；对话变长时按设置自动压缩较早的内容。

发送前确认

「发送前确认内容」打开时，每次分析都会先显示将要发送的内容。发送前会替换玩家名、访问令牌、UUID、用户目录和 IP 地址等隐私信息，你可以检查后再发送。

使用

  1. 游戏崩溃时，启动器的崩溃分析页可以直接「用 AI 分析」，自动新建会话并带上日志；也可以点顶栏的「AI」自己描述问题。
  2. AI 需要更多信息时会调用下面的查看接口，例如读日志、列模组、看配置。
  3. 需要修改时，对话里会出现确认卡片，写明要执行的操作和影响。允许后才会真正执行。
  4. 修改类操作在本次对话中可以「允许同类操作」；删除、替换、恢复这类危险操作每次都要单独确认。

启动器提供的操作接口

AI 只能调用下面这些固定接口，不能执行任意命令、访问任意网址或读写游戏文件夹之外的文件。下载只通过 Modrinth 的接口解析，AI 不能指定下载地址。

查看类（默认直接执行）

接口说明
list_versions列出游戏文件夹中已安装的版本与当前选择的版本。
get_version_info加载器、Java 与内存设置、模组数量、存档列表、运行目录。
list_mods列出一个版本的模组文件，以及是否启用。
list_files列出运行目录中某个文件夹的内容，例如 config、saves。
read_log读取最近一次日志、最新崩溃报告或调试日志；只截取错误相关部分并去除隐私信息。
search_mods在 Modrinth 搜索与指定版本兼容的模组。
search_resources在 Modrinth 搜索模组、光影、资源包、数据包或整合包，可按下载量等排序。
get_project查看 Modrinth 项目的详情、支持的游戏版本与兼容版本。
list_game_versions列出可以安装的 Minecraft 版本（正式版、快照等）。
list_loader_versions列出某个版本可用的加载器版本，并标注推荐的稳定版。
list_javas列出启动器找到的 Java 和全局设置的 Java。
system_info操作系统、内存、处理器和显卡（含驱动版本）。
list_backups列出一个版本的备份及包含的内容。

如果打开「查看类操作也需要确认」，这些操作在执行前也会显示确认卡片。

修改类（本次对话可允许同类操作）

接口说明
install_game安装 Minecraft 版本，可同时安装加载器与 OptiFine；完成后设为当前版本。
select_version切换启动页当前选择的版本。
install_mod从 Modrinth 安装模组，并一并安装必需的前置模组。
install_resource安装光影包、资源包或数据包；数据包需要指定存档。
set_mods_enabled启用或禁用模组（禁用时在文件名后加 .disabled）。
set_version_java把某个版本的 Java 设为跟随全局、自动选择或已找到的某个 Java。
set_version_memory把某个版本的内存设为跟随全局、自动或自定义大小。
backup把存档、模组、配置等打包备份到游戏文件夹的 backups。

危险操作（每次都要确认）

接口说明
edit_config修改 config 中的文件或 options*.txt：原文必须在文件中唯一，修改前自动备份。
delete_files删除运行目录中的文件或文件夹；文件移到回收站，可以从回收站恢复。
replace_mod用 Modrinth 上的另一个版本替换模组：先备份旧文件，再把旧文件移到回收站。
restore_backup从备份恢复：先把当前的对应内容备份并移到回收站，再解压并校验备份。

安全与边界

  • 所有文件操作都限制在游戏文件夹内，路径会做规范化检查；确认之后执行前还会再检查一次，防止期间被替换成链接。
  • 修改配置、替换模组、恢复备份前都会先备份；删除的文件移到系统回收站。
  • 备份带有签名与内容摘要，恢复前会校验；旧版创建的无签名备份会提示无法确认完整性。
  • 日志会截取错误相关部分，并在发送前替换玩家名、令牌、UUID、用户目录和 IP 地址。
  • API Key 在 Windows 上加密保存；macOS 与安卓暂时还没有使用系统密钥库，会保存在启动器的私有数据目录中。
  • 暂不支持让 AI 安装整合包；它能搜索到整合包，但不能直接安装。
  • AI 看到的工具结果也会发送给你配置的模型服务；使用本机 Ollama 时数据不会离开本机。

常见问题

提示还没有配置接口

到「设置 → AI 排障」选择接口类型，填写地址、模型和 API Key。本机服务可以不填 Key；填完可以点获取模型列表确认接口可用。

获取模型列表失败

有些服务不提供模型列表接口，可以手动填写模型 ID。也检查地址是否包含了正确的版本路径（例如 OpenAI 兼容接口通常以 /v1 结尾）。

AI 只肯回答，不肯动手

确认「允许 AI 操作游戏文件」已经打开；关闭时 AI 只能聊天，不能调用查看或修改接口。

对话很长以后回答变慢或忘记前面

调整「上下文长度」，或打开自动压缩。也可以新建对话，只带上相关的日志。
