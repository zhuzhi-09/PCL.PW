使用指南

安卓版

安卓版内置 Java 运行时和游戏库，不需要安装 Java，也不需要用第三方启动器。要求 Android 8.0 及以上、64 位 ARM 处理器。

第一次打开

  • 启动器会询问把游戏文件放在哪里。可以选公共目录（方便用文件管理器查看），也可以放在应用自己的目录里。
  • 如果选择了公共目录，可能需要授予文件夹访问权限；之后可以在「设置 → 游戏管理」里修改。
  • 账户、Java、版本和模组的使用方式与桌面版相同，见 第一次启动。

支持的版本

内置运行时支持 Minecraft 1.0 到最新版本的 Java 版。具体能跑多快取决于手机性能、内存和渲染器；较新的版本对手机要求更高。

渲染器

在「设置 → 启动 → 渲染器」里选择；也可以在版本设置里为单个版本另选。

渲染器说明
自动按显卡自动选择，目前几乎所有设备都会用 MobileGlues。
MobileGlues（推荐）OpenGL 转 OpenGL ES，速度快，支持所有版本；旧版本会自动加上 SFPEW 模拟固定管线。
Zink（OpenGL 转 Vulkan）基于 Vulkan，Adreno 显卡上使用 Turnip 驱动；部分设备上更稳定。
系统 GLES 驱动直接用系统的 GLES 驱动，只适合支持 GLES 的模组，兼容性有限。

切换渲染器后需要重新启动游戏。如果进入游戏黑屏或崩溃，先换回「自动」或 MobileGlues 试试。

渲染比例

「设置 → 启动 → 渲染比例」控制游戏画面相对屏幕分辨率的比例。调低后画面会更模糊，但帧率更高、发热更少，适合性能有限的手机。每个版本也可以单独设置。

触屏操作

游戏内提供触屏按键和摇杆，可以用屏幕模拟键盘与鼠标操作。游戏切到后台再回来时，首页的大按钮会变成「返回游戏」，旁边单独有一个结束按钮。

游戏内助手

游戏画面上有一个可拖动的小球，点一下打开菜单：

  • 基础信息：内存、CPU、温度和运行时长；使用 Zink 渲染器时还能看到帧率。MobileGlues 等渲染器不会通知应用每一帧是否画完，所以帧率显示为「--」。
  • 问 AI：打开完整的对话窗口，支持 Markdown、多会话和逐字回答；左侧会话栏可以折叠，拖动窗口右下角可以调整大小。请求通过后台运行的启动器发出，API Key 不会进入游戏进程；需要先在「设置 → AI 排障」里配置好接口和模型。
  • 隐藏：隐藏小球；右上角的「助手」按钮可以重新打开。也可以在「设置 → 启动 → 游戏内叠加层」里关闭。

小球会记住拖动后的位置，靠近屏幕边缘时会自动吸附；5 秒没有点击或拖动会淡出，触摸后恢复。打开游戏菜单（例如背包）时，展开的面板会自动收起，避免挡住操作。

在「设置 → 启动」里可以关闭整个「游戏内叠加层」，也可以单独关闭「游戏内 AI」或「提问时附带最近日志」。关闭日志附带后，问 AI 时不会自动发送游戏日志末尾。

已知限制

  • 暂时不能安装需要运行安装器的 Forge、NeoForge、Cleanroom 与 OptiFine；可以用 Fabric、Quilt 等不需要安装器的加载器。在手机上运行安装器的能力还在开发中。
  • 账户与 AI API Key 目前还没有使用 Android Keystore 加密，计划在后续版本加入。
  • 手柄支持、自定义按键布局和更多渲染器选项还在计划中。

性能建议

  • 优先用 MobileGlues 渲染器，必要时降低渲染比例。
  • 内存不要分配超过手机实际可用内存；「设置 → 启动 → 游戏内存」默认自动分配。
  • 大型整合包和光影对手机压力很大，建议先用原版或轻量模组测试。
