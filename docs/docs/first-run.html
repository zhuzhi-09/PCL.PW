使用指南

第一次启动

打开启动器后，按顺序完成这几步就能进游戏。设置都可以之后再改。

1. 选择游戏文件夹

游戏文件夹（通常叫 .minecraft）保存版本、模组、存档和资源。默认位置在启动器的用户数据目录里，也可以直接使用已有的游戏文件夹。

  • 在「设置 → 游戏管理」里查看当前文件夹，或者添加一个新的文件夹。
  • 安卓版第一次打开时会询问把游戏文件放在哪里；之后可以在同一个位置修改。
  • 如果你之前用 PCL 或 PCL-CE，可以在「设置 → 其他 → PCL-CE」里导入游戏文件夹、启动设置和账户。

2. 添加账户

在首页左侧点账户头像，选择微软正版或离线账户。离线账户填一个名字即可，适合没有正版或只想本地测试的时候。

key

微软正版登录暂时需要自己填写 Azure 应用 Client ID。由于作者暂时未通过微软云开发者的支付验证，两个月内暂时不会内置默认的 Client ID，也就没有开箱即用的「正版验证支持」。

需要正版登录的话，请到 Azure 门户注册一个「个人 Microsoft 账户」类型的公共客户端应用，在「身份验证」里开启“允许公共客户端流”，然后把应用 ID 填到「设置 → 其他 → 正版登录 → Azure 应用 Client ID」。不填的话会提示需要填写 Client ID，只能使用离线账户。

Windows 上账户凭据（包括微软账户的刷新令牌）会用系统 DPAPI 加密后保存，不会以明文写进配置文件；安卓与 macOS 上使用系统密钥库的支持还在计划中。

3. 准备 Java

启动器会自动查找本机安装的 Java。找不到需要的版本时，会按游戏版本的要求自动下载 Mojang 提供的 Java（Java 8 / 17 / 21 等）。

  • 在「设置 → Java」里可以看到检测到的 Java，也可以手动指定某个 javaw.exe 或 java 路径。
  • 「设置 → 启动」里的「游戏内存」默认自动分配；内存很小或很大的机器建议改成自定义。
  • 安卓版使用内置运行时，不需要自己安装 Java。

4. 安装一个游戏版本

打开「下载」，选择原版游戏版本（正式版、快照、远古版或愚人节版本），点安装。也可以顺便装上 Forge、Fabric 等加载器，详见 版本与加载器。

下载会优先使用你选择的下载源（官方源或 BMCLAPI 镜像），失败时自动回退；每个文件都会做校验。

5. 选择版本并开始游戏

  1. 回到首页，点「版本选择」选中刚装好的版本。
  2. 点「开始游戏」。第一次启动要准备资源文件，会比之后慢一些。
  3. 游戏运行后，首页的大按钮会变成「结束游戏」；安卓上游戏切到后台后可以点「返回游戏」。

接下来

  • 想装模组、光影或资源包：看 模组与资源。
  • 想让每个版本用不同的 Java、内存或隔离规则：看 版本与加载器。
  • 游戏启动失败：首页点「游戏日志」，或者看 常见问题与排错。
