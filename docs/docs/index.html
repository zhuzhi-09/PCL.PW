PCL.PW 文档

文档

PCL.PW 是 PCL 的第三方衍生作品，一个跨平台的 Minecraft Java 版启动器，支持 Windows、Android 与 macOS。这里是从安装到排错的完整说明。

info

PCL.PW 由第三方独立开发和维护，与 PCL 及其作者龙腾猫跃无关，也不代表 PCL 官方。遇到本软件的问题请到 GitHub Issues 反馈，不要打扰 PCL 作者。

download 下载与安装 Windows、macOS、Android 的安装包与首次打开提示。 rocket_launch 第一次启动 游戏文件夹、账户、Java 和第一个游戏版本。 smartphone 安卓版 内置运行时、渲染器选择、触屏操作与已知限制。

使用指南

  • 下载与安装：系统要求、安装版与便携版的区别、GitHub 下载慢时怎么办。
  • 第一次启动：选择游戏文件夹、添加账户、准备 Java、安装并启动第一个版本。
  • 版本与加载器：原版与 Forge、NeoForge、Fabric、Quilt 等加载器，版本隔离与每个版本单独的设置。
  • 模组与资源：从 Modrinth 安装模组、光影、资源包和数据包，管理存档与截图，局域网互传。
  • 安卓版：支持的版本、渲染器、渲染比例和安装器限制。
  • 常见问题与排错：看日志、崩溃分析、更新与反馈。

接口

启动器接口 说明了更新检查与公告读取的地址、update.json 与 notices.json 的字段和格式版本规则。
