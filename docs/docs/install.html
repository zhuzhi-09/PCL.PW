下载与安装

所有版本都在 GitHub Releases 发布。正式版最稳定，Nightly 是每次提交后自动构建的测试版。

系统要求

平台要求安装包
WindowsWindows 10 及以上，64 位安装版 *-setup.exe、便携版 *-portable.zip
macOSmacOS 12 及以上，Apple 芯片与 Intel 通用*-macos.dmg
AndroidAndroid 8.0 及以上，64 位 ARM*-android-arm64.apk
Linux尚未适配—

Windows

安装版（推荐）

  1. 下载 PCL.PW-版本号-windows-x64-setup.exe 并运行。
  2. 安装程序只为当前用户安装，不需要管理员权限，默认装到 %LOCALAPPDATA%\Programs\PCL.PW，安装目录可以修改。
  3. 安装版可以在启动器里检查并自动更新。

首次运行时 Windows SmartScreen 可能提示「Windows 已保护你的电脑」，点「更多信息」→「仍要运行」即可。安装包来自本项目的 GitHub Releases，可以在那里核对文件来源。

便携版

下载 *-portable.zip 解压到任意目录，运行其中的 PCL.PW.exe。适合放在 U 盘里，或者不想安装的时候使用。便携版也能在启动器内更新，更新时会替换程序文件。

安装版与便携版共用同一份用户数据（设置、账户、默认游戏文件夹），换一种方式打开不会丢配置。

macOS

  1. 下载 *-macos.dmg，打开后把 PCL.PW 拖进「应用程序」文件夹。
  2. 第一次打开时，如果提示「无法验证开发者」或「Apple 无法检查 App 是否包含恶意软件」，打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」；也可以右键 App 选择「打开」。
warning

PCL.PW 没有经过 Apple 公证，所以会有上面的提示。应用本身是开源的，可以自行从源码构建。更新时打开下载好的 dmg，把新的 PCL.PW 拖进「应用程序」覆盖旧版本即可，游戏文件不受影响。

Android

  1. 下载 *-android-arm64.apk，用文件管理器或浏览器打开。
  2. 系统会提示「禁止安装未知应用」，按提示允许当前应用安装，然后确认安装。
  3. 要求 Android 8.0 及以上、64 位 ARM 处理器；x86 设备暂时不支持。

安卓版不在应用商店上架。覆盖安装会保留游戏、账户和设置；第一次打开时会询问游戏文件夹放在哪里，详见 安卓版。

Nightly 测试版

每次向 main 分支推送后，工作流会自动构建 Nightly，发布在 nightly 标签下，包含最新的改动，也可能不稳定。想尝鲜或者帮忙测试时可以下载；日常使用建议选正式版。

下载慢或打不开 GitHub

可以先到 竹纸软件下载站 下载，那里会同步最新正式版。启动器内的游戏下载也支持 BMCLAPI 镜像：在「设置 → 其他 → 下载」里把下载源换成 BMCLAPI，失败时还会自动回退到官方源。

校验下载的文件

update.json 中每个发布文件都有 size 与 sha256，可以用系统自带的工具核对，例如 Windows 上：

certutil -hashfile PCL.PW-0.3.3-windows-x64-setup.exe SHA256

启动器自己下载更新时也会核对大小与 SHA-256，校验不通过会删除文件并报错。
