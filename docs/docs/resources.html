使用指南

模组与资源

PCL.PW 内置 Modrinth 搜索，可以直接把模组、光影、资源包和数据包装到当前版本，不需要手动找 .minecraft 的各个子目录。

从哪里安装

打开「下载」→「资源」，选择类型：

类型安装位置说明
模组mods需要对应游戏版本和加载器；会提示缺少的前置模组并一起安装。
光影包shaderpacks需要 Iris、OptiFine 等支持光影的加载器。
资源包resourcepacks材质与音效，原版即可使用。
数据包datapacks作用于存档或整个游戏。

列表会按当前版本的游戏版本和加载器筛选；装到哪个版本、装什么类型在顶部选择。下载完成后文件会直接放进对应目录，并记录已安装的项目。

info

模组必须和游戏版本、加载器匹配。例如 Fabric 模组不能装到 Forge 版本上；版本不匹配时列表里可能根本搜不到，或者装好后游戏报错。先确认当前版本用的是哪个加载器，见 版本与加载器。

启用与禁用模组

已经装好的模组可以在版本的文件列表里启用或禁用，不需要删除文件。排查模组冲突时，可以先禁用一半再逐步缩小范围。

存档、截图与文件管理

在版本页面可以打开游戏文件夹，查看存档、截图、日志和配置文件。删除、重命名这些文件前会要求确认；版本隔离打开时，它们位于 versions/版本名 下。

局域网互传

同一局域网里的两台设备都打开「工具 → 局域网互传」，输入对方显示的地址和配对码即可传输：

  • 游戏版本；
  • 模组、配置和存档。

适合在没有网络或不想走云盘的时候，把电脑上的整合搬到手机上，或者反过来。传输只在局域网内进行，不经过第三方服务器。

下载与校验

模组和资源从 Modrinth 的官方接口获取。启动器的游戏文件下载支持官方源与 BMCLAPI 镜像、多线程和校验；这些设置在「设置 → 其他 → 下载」里。
