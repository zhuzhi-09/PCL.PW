版本与加载器

「下载」页负责安装游戏本体和加载器；首页和「版本选择」负责管理已经装好的版本。

安装原版

在「下载」里选择 Minecraft 原版，可以安装：

  • 正式版与快照；
  • 远古版本；
  • 愚人节版本。

下载源可选官方源或 BMCLAPI 镜像，失败时自动回退；支持多线程下载，每个文件都会校验，结尾连接卡住时会自动换节点重试。

安装加载器

安装原版时可以一起选择加载器，也可以之后单独安装。支持：

加载器说明
Forge覆盖大多数游戏版本，模组生态最大。
NeoForge较新版本上的 Forge 分支，常见于 1.20.2 之后的整合包。
Fabric轻量，更新快，很多现代模组使用。
QuiltFabric 的分支，兼容大部分 Fabric 模组。
Legacy Fabric为旧版本准备的 Fabric。
LiteLoader旧版本上的轻量加载器，通常与 Forge 一起使用。
Cleanroom1.12.2 上基于 Forge 的现代 Java 兼容方案。
OptiFine可以独立安装，也可以作为模组与 Forge 等一起安装。
LabyMod带客户端功能的整合加载器。

安装时会依次完成下载安装器、运行、合并版本 JSON 等步骤，进度显示在「任务」和首页的启动按钮上。安装完成后，加载器会作为一个新的版本出现，例如 1.20.1-forge-47.2.0。

info

安卓上暂时不能安装需要运行安装器的 Forge、NeoForge、Cleanroom 与 OptiFine，可以用 Fabric、Quilt 这类不需要运行安装器的加载器。具体见 安卓版。

管理版本

  • 版本选择：首页左侧的按钮，切换当前要启动的版本。
  • 改名与复制：在版本列表里操作，复制适合在同一个游戏版本上做不同的模组组合。
  • 删除：删除版本文件夹；存档等如果在该版本的隔离目录里也会一起删掉，操作前会确认。
  • 版本设置：首页的「版本设置」进入当前版本的单独配置。

版本隔离

版本隔离决定每个版本是否使用自己的 mods、saves、config 等目录。在「设置 → 启动 → 版本隔离」里选择规则，新版本第一次启动时按规则决定，之后可以在版本设置里单独修改。

规则行为
关闭所有版本共用游戏文件夹根目录下的模组与存档。
隔离可安装 Mod 的版本Forge、Fabric 等能装模组的版本使用自己的目录。
隔离非正式版快照、远古版等非正式版使用自己的目录。
隔离可安装 Mod 的版本与非正式版以上两类都隔离。
隔离所有版本每个版本都使用 versions/版本名 下的独立目录（默认）。

规则的判断方式与 PCL-CE 相同，从 PCL-CE 迁移过来的版本文件夹可以直接使用。

每个版本单独的设置

在「版本设置」里可以覆盖全局设置，常见的包括：

  • 使用的 Java（自动选择或手动指定）；
  • 游戏内存（自动或自定义）；
  • JVM 参数、游戏参数；
  • 窗口大小与启动后行为；
  • 启动前执行的命令；
  • 安卓上的渲染器与渲染比例。

没有单独设置的项会跟随「设置」里的全局值。
