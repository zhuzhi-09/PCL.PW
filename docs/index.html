常见问题

和 PCL、PCL-CE 是什么关系？expand_more

PCL.PW 是 PCL 的第三方衍生作品：界面布局参考 PCL-CE，用 Flutter 重新编写，视觉采用 Material Design 3，并增加了安卓版。它由第三方独立开发，与 PCL 和 PCL-CE 官方无关。可以从 PCL-CE 导入设置、游戏文件夹和账户。

安卓版能玩哪些版本？expand_more

支持 1.0 到最新的 Java 版，也能在手机上安装 Forge、NeoForge、OptiFine 等加载器。帧率取决于手机性能和所选的渲染器。

安装时提示「未知来源」或被拦截？expand_more

安卓版不在应用商店上架，需要允许浏览器或文件管理器安装应用。Windows 上如果 SmartScreen 提示，点「更多信息」→「仍要运行」。安装包都可以在 GitHub 上核对来源。

遇到问题去哪里反馈？expand_more

请在 GitHub Issues 反馈，不要打扰 PCL 的作者。
