## 新增

- 安卓支持 TouchController 模组（基岩版风格的触控）：版本的 mods 文件夹里装了它时，游戏内的触摸转发给它，启动器自带的摇杆和按键自动隐藏；菜单里仍用原来的点按操作。
- 顶栏后台任务：没有下载任务时，游戏运行中显示「1 个游戏实例运行中」。
- 安卓新增渲染器 Krypton Wrapper（NG-GL4ES R0.4.5）：OpenGL 转 OpenGL ES，速度快，自带固定管线支持，效率比 Zink 高，新旧版本都能用，能运行 Sodium 和部分光影；渲染器设为「自动」时默认使用它（26.x 版本改用 MobileGlues）。26.3 快照起的版本暂不可用。内置的 Krypton Wrapper 打了补丁，修复了 Xaero 小地图花屏；用它时游戏切到后台也不再崩溃。
- 首页新增「更新日志」提示条，显示当前版本的更新内容，可以展开阅读全文；关闭后同一个版本不再提示，换版本后自动重新出现。
- 工具页新增「使用文档」：在启动器内阅读官网文档，可以切换页面；断网时显示最近一次缓存。
- 安卓版下载 Java 时，GitHub 连接卡住或速度过低会自动改用 ghproxy 镜像；下载和解压都显示确定进度，连接来源、速度和大小写在任务详情里。
- 电脑端下载 Java 运行时也显示已下载大小、平均速度和下载源；macOS Apple 芯片的 Zulu 8 改成按字节显示进度，不再从 0/1 直接跳到 1/1。
- 从 GitHub 下载的文件（macOS Apple 芯片的兼容库、文档的备用源）直连失败或卡住时，会自动尝试 ghproxy 镜像。
- 安卓游戏内新增助手小球：点开可以查看基础信息（帧率、内存、CPU、GPU 占用、温度、运行时长；帧率支持所有 OpenGL 渲染器，26.x 版本暂时读不到），也可以直接「问 AI」或回到启动器。小球可以拖到任意位置，松手后平滑吸附到最近的一侧；闲置几秒后变淡并半藏到屏幕边缘，点一下就出来。菜单在小球旁边弹出，不再把小球顶走。菜单里可以打开「常驻简略信息」，在屏幕顶部常驻显示帧率、内存、CPU、GPU 和温度，默认靠左，可以左右拖动并记住位置，隐藏小球后也会保留。设置里可以关闭整个叠加层，也可以单独关闭「游戏内 AI」或「提问时附带最近日志」。
- 游戏内 AI 与启动器的「AI」页共用同一份对话记录：在游戏里问的问题回到启动器就能看到，启动器里的对话也能在游戏里接着聊；AI 请求由启动器发出，密钥不会进入游戏进程。游戏内也能使用启动器操作：需要确认的操作（安装模组、修改内存等）会在游戏内窗口和启动器里同时显示确认卡片，任意一边确认即可；AI 会说明改动何时生效——光影包、资源包可以在游戏里立即切换，模组、Java、内存等需要重启游戏。窗口改为半透明背景，气泡、按钮和输入框用白色细边框，大小自动适配屏幕；支持停止回答、复制回答，窗口贴着助手小球展开，拖动远离小球的下角可以调整大小（双击恢复默认），关闭窗口不会中断回答。旧版本保存在游戏内的对话会自动导入启动器。
- 下载页的 Modrinth 整合包现在可以直接安装：自动识别整合包需要的 Minecraft 与加载器，安装为独立的隔离版本，下载整合包里的模组并解压配置与覆盖文件；也可以选择本地的 `.mrpack` 文件安装。
- AI 工作区：AI 有一个自己的文件夹，可以随意读写，用来存放整理结果、清单等；还能查看当前版本的游戏文件（只读），以及你在设置里添加的文件夹（默认只读，可以单独允许修改）。能访问哪些文件夹只能由你在设置里决定。修改文件需要你确认，删除会移到回收站。
- AI 联网搜索：不需要任何 Key 就能搜索网页（默认用 Exa，失败时依次改用 DuckDuckGo、必应），能打开网页阅读正文，也能搜索 Minecraft Wiki；请求跟随系统代理。也可以在设置里改用 SearXNG、Tavily、Brave 或 Serper。查模组、光影、资源包时可以直接按游戏版本和加载器筛选，不需要先安装那个版本，也能一次比较多个项目。
- AI 页右侧新增可以收起的侧边栏：显示当前模型、版本、工作区与联网状态，上下文用量，这次对话里 AI 写过的文件，以及工作区里的文件。新增内置的文件查看器，Markdown 文件直接排版显示，也可以切换查看源码。
- 电脑端首页改为单独的排版：第一屏只放常用的内容并铺满窗口，最近游玩改为紧凑横条；版本动态、当前版本信息和提示往下滚动查看。窗口较小时界面自动缩小到 0.9 倍。电脑端工具页改回左侧二级菜单。
- 安卓：左侧导航栏新增「文件」，打开内置文件管理器；选择 Java、整合包、日志文件以及选择保存位置时，都改用内置文件管理器（选择图片仍然用系统相册）。
- 首页主视觉的渐变、按钮和方块风景会跟随主题色生成，不再固定为绿色；浅色模式显示太阳、深色模式显示月亮，点击太阳或月亮可以切换明暗模式。
- 外置登录（authlib-injector）。

## 修复

- 安卓：游戏内新增「使用」按键，按住即按住右键，可以吃东西、喝药水、拉弓、举盾；之前点屏幕只会短按右键，长按是挖掘，无法进食。

- 安卓：游戏进程里关闭网络连接时可能直接被系统信号结束（表现为打开游戏内 AI 后突然闪退）。启动游戏时不再重置安卓保留的实时信号，游戏内 AI 断开连接时也不再触发这个信号。

- Windows：启动器的数据改放到 `%LOCALAPPDATA%\Pixel World`（Java 运行时、AI 工作区、对话记录等），配置、账户和 AI 的 Key 留在 `%APPDATA%\Pixel World`，不再多套一层同名文件夹；第一次启动时自动迁移，已下载的 Java 不用重新下载。配置和账户还会在启动器所在文件夹的 `backup` 里备份一份，AppData 被清理时自动恢复。
- 设置里的微软登录 Client ID 不再显示启动器内置的值。

- 游戏内「Java 已用 / 上限」改为读取游戏 JVM 自己的堆，不再把 Android 运行时的 0.5 GB 当成 Java 内存。
- 安卓第一次安装 APK 更新时，如果还没有授予「安装未知应用」，不再报错并要求重新下载；安装包会保留，授权后点「继续安装」即可。
